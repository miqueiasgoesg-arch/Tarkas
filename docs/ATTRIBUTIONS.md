# Atribuições de fontes

## Mapas táticos

Os arquivos SVG em `assets/maps/` são derivados do projeto público
[tarkov-dev-svg-maps](https://github.com/the-hideout/tarkov-dev-svg-maps),
usado pelo Tarkov.dev. Eles são licenciados sob
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

O Tarkas mantém essa atribuição no aplicativo e não usa esses mapas para
radar, ESP, automação, leitura de memória ou qualquer vantagem indevida dentro
do jogo. O material de mapas não pode ser usado comercialmente sem uma licença
compatível.

Dados estruturados de itens, quests, mapas e economia vêm do
[Tarkov.dev](https://tarkov.dev/), conforme disponibilidade da fonte.
