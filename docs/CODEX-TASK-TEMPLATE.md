# Template de tarefa Codex — Econômico

## Objetivo
Descreva uma entrega concreta em 1–3 frases.

## Escopo fechado
- Item 1
- Item 2
- Item 3

## Fora do escopo
- Não criar melhorias adicionais.
- Não refatorar áreas não relacionadas.
- Não gerar build completa durante microetapas.

## Critérios de aceite
- Função solicitada implementada.
- Testes direcionados passam.
- Sem regressão evidente no fluxo tocado.
- Estado do projeto atualizado de forma concisa.

## Testes
1. Rodar somente checks/testes relacionados durante implementação.
2. Fazer validação mais ampla uma única vez no fechamento.
3. Build/instalador apenas se solicitado ou se este pacote for release.

## Encerramento
Ao atingir os critérios de aceite, parar. Retornar apenas:
Alterações | Testes | Problemas | Próximo passo.
